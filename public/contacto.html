Formulario de Contacto

Envía tu Mensaje

Completa el formulario a continuación y presiona "Enviar". Los datos serán procesados por el servidor Express mediante POST.

🔍 Cómo Funciona Ahora:

  1. JavaScript fetch: El formulario usa fetch() para enviar datos como JSON
  2. Envío asíncrono: Los datos se envían a /api/contacto sin recargar la página
  3. Procesamiento: Express recibe los datos JSON en req.body
  4. Respuesta: El servidor devuelve un mensaje personalizado en JSON
  5. UI dinámica: La respuesta se muestra en la misma página sin navegación
