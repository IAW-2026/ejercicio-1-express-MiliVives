Este proyecto demuestra cómo manejar diferentes rutas en un servidor Express.

¿Qué es una Ruta en Express?

Una ruta define cómo responde la aplicación Express a una solicitud de cliente hacia un endpoint específico. Cada ruta puede devolver contenido HTML diferente.

📍 Rutas disponibles en este proyecto:

  • ✅ / (Inicio) - Página principal (estás aquí)
  • ✅ /acerca - Información sobre el sitio
  • ✅ /contacto - Formulario de contacto
  • ✅ /encuesta - Formulario con selección
  • ✅ /productos - Consumo de API JSON con fetch
