Acerca de Este Sitio

¿Quién Somos?

Este es un proyecto educativo desarrollado con Express.js para aprender a manejar múltiples rutas y entregar contenido HTML diferente en cada una de ellas.

Objetivo del Proyecto

  • ✅ Comprender cómo funcionan las rutas en Express
  • ✅ Servir archivos estáticos (HTML, CSS, JavaScript)
  • ✅ Conectar múltiples páginas HTML entre sí
  • ✅ Practicar navegación web básica

Tecnologías Utilizadas

Node.js Express.js HTML5 CSS3 JavaScript

Estructura del Proyecto

📁 public/ - Carpeta de archivos estáticos
  ├── index.html (Página Principal)
  ├── acerca.html (Esta página)
  ├── contacto.html (Página de Contacto)
  ├── styles.css (Estilos compartidos)
  └── script.js (JavaScript compartido)
📄 app.js - Servidor Express con rutas
